# Lizart Shop — Копия сайта для переноса на Cloudflare Pages

Полная статическая копия сайта **https://lizart-shop.tilda.ws/**, оптимизированная для быстрого и независимого хостинга на **Cloudflare Pages** (или любом другом статическом хостинге / CDN).

---

## 📁 Структура проекта

```
lizart-shop/
├── index.html              # Главная страница сайта (все блоки, каталог, карточки)
├── 404.html                # Страница ошибки 404
├── page260902009.html      # Страница/шаблона шапки
├── page270415909.html      # Дубликат для обратной совместимости со старыми ссылками
├── robots.txt              # Конфигурация для поисковых роботов
├── sitemap.xml             # Карта сайта
├── _headers                # Настройки заголовков и кэширования для Cloudflare Pages
├── _redirects              # Правила перенаправлений для Cloudflare Pages
├── css/                    # 12 CSS-файлов Tilda + fonts.css
├── js/                     # 19 JS-скриптов для анимаций, слайдеров, зума, каталога
├── fonts/                  # 37 WOFF2-шрифтов (Montserrat и Tinos, cyrillic/latin)
├── images/                 # 37 оригинальных изображений в высоком разрешении и векторных SVG
└── _source_tools/          # Исходные скрипты скачивания и обработки (архив)
```

## 🚀 Как развернуть на Cloudflare Pages

### Способ 1: Прямая загрузка (Direct Upload)
1. Зайдите в панель управления [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Перейдите в раздел **Workers & Pages** -> **Create application** -> вкладка **Pages** -> **Upload assets**.
3. Назовите проект (например, `lizart-shop`).
4. Загрузите содержимое папки `lizart-shop` (или упакуйте её в zip и загрузите).
5. Нажмите **Deploy site** — сайт сразу заработает на поддомене `*.pages.dev`.
6. В настройках **Custom domains** подключите ваш собственный домен.

### Способ 2: Через Git (GitHub / GitLab)
1. Создайте репозиторий на GitHub и отправьте в него файлы.
2. В Cloudflare Pages выберите **Connect to Git** и выберите репозиторий.
3. Build command: оставить пустым (статический сайт).
4. Build output directory: оставить корневую `/` (или путь к папке).
5. Нажмите **Save and Deploy**.

## 🛠 Что было сделано

1. **Полная автономность от Tilda CDN**:
   - Все 14 стилевых таблиц и 19 скриптов выгружены локально и распакованы в чистый читаемый UTF-8 (устранены бинарные gzip-артефакты).
   - Скрипты отслеживания Tilda (`tilda-stat`) отключены, чтобы сайт не делал медленных фоновых запросов к серверам Тильды.
   - Механизм fallback-запросов нейтрализован, сайт работает полностью независимо.

2. **Локализация шрифтов**:
   - Шрифты **Montserrat** и **Tinos** (латиница и кириллица) полностью выкачаны в современном формате `.woff2`.
   - Запросы к Google Fonts заменены на локальный `css/fonts.css` для максимальной скорости загрузки и соответствия приватности.

3. **Оригинальное качество изображений**:
   - Извлечены и выгружены полные исходные изображения вместо 20-пиксельных превью `/-/resizeb/20x/`.
   - Картинки привязаны напрямую к локальным путям в `images/`.

4. **Готовность к Cloudflare**:
   - Добавлен `_headers` для настройки мгновенного кэширования статики (`immutable`) и безопасности (`nosniff`, `SAMEORIGIN`).
   - Добавлен `_redirects` для чистых редиректов.
   - Сгенерированы `robots.txt` и `sitemap.xml`.
